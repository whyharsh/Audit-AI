# Project Brief

## Working Idea

Build AI for financial audits and evidence trails that Chartered Accountants and audit officers can use during real audit work.

## Users

- Chartered Accountants
- audit officers
- audit teams reviewing financial records, source documents, and compliance evidence

## Open Questions

- Which audit workflows should be supported first?
- What evidence sources matter most: ledgers, bank statements, invoices, tax filings, confirmations, emails, PDFs, spreadsheets, or ERP exports?
- Should the first version be a local tool, web app, internal audit workspace, or document review engine?
- What compliance standards and jurisdiction-specific requirements should shape the product?
- How should the system present confidence, exceptions, and missing evidence?
